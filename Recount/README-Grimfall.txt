RECOUNT WITH INTEGRATED GRIMFALL SUMMON FIX

INSTALL
1. Exit WoW completely.
2. Remove the separate RecountGrimfallSummons addon folder if installed.
3. Extract the Recount folder from this ZIP into Wotlk\Interface\AddOns.
   Allow existing Recount addon files to be replaced.
   The final path must be Interface\AddOns\Recount\Recount.toc.
4. Restart WoW and enable Recount.
5. Summon fresh Greater Skeletal Warriors while grouped and nearby.
   Enable Merge Pets w/ Owners to include their damage in the owner's total.

The existing working compatibility fix is now loaded inside Recount.
Only one addon folder is needed. Each person who wants the corrected
meter should install this version. Saved settings and fights in WTF
are not included or overwritten by this package.

The fix covers Greater Skeletal Warriors (NPC 4335, owner aura 807927).
It does not recover missing ownership for past fights. Updating Recount
from another source may replace its load list and disable this fix.

The recorder addon is no longer needed for this fix.
